# tooo

tooo 是一个待办和计时应用。这个插件把你的 AI 助手连到 tooo：读写任务和步骤、开始和暂停计时、补记用时、查看日复盘和周复盘、设提醒。插件里只有连接地址 `https://app.tooo.site/mcp`，没有密钥；首次连接时由 tooo 账号的所有者在自己的设备上批准。账号目前是邀请制，不开放注册。tooo 把删除任务、停止重复、撤销开始计时、去掉已记时间标为每次都要确认。

tooo is a to-do list and focus timer. This plugin connects your AI assistant to tooo so it can read and write tasks and steps, start and pause the timer, log time, read the day and week review, and set reminders. It holds only the connection address `https://app.tooo.site/mcp` and no secrets. The tooo account owner approves the first connection on their own device. Accounts are invite-only for now, and tooo marks deleting a task, stopping a repeat, undoing a timer start and cutting recorded time as needing confirmation every time.

Install steps for Claude apps, Claude Code and Codex are in the [repository README](../../README.md). License: MIT.
